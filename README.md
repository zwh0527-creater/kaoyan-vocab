# 考研单词

个人使用的离线背词 PWA。每天中午 12 点刷新，最多 15 组、每组 20 词；只有明确标为熟词的词退出学习池，其余词在整轮结束后继续学习。

支持中文反查和英文查词，并显示熟词状态。词条始终先展示考研大纲原释义，红宝书释义作为有页码的补充；英语一真题记录来自本地 2010—2025 真题合集，提供完整原句、中文译文和用法结构。带明确题号且能与本地答案资料逐题对应的内容标为“官方译文”，其余由免费本地模型生成并标为“辅助翻译”。固定搭配、例句及相关词来自红宝书本地 OCR 提取，并区分“原书未设词组栏”和“OCR 未形成可靠条目”。

线上版本：https://zwh0527-creater.github.io/kaoyan-vocab/

词库来自 `考研大纲词汇乱序版.pdf`，提取后共 5493 条。两个 `coordinate` 条目含义不同，按原 PDF 顺序保留；原 PDF 不会打包进 App。学习进度只保存在当前设备，可在设置页导出和导入 JSON 备份。

## 学习规则

- 每次只显示当前 20 词小组，中文释义默认隐藏。
- 未标熟词不会第二天立刻重复；当前整轮完成后，它们才进入下一轮。
- 熟词进入熟词本。只有逐词点击“重新学习”，对应单词才回到下一轮队列。
- 详解优先提供可核对的红宝书固定搭配；没有单列搭配时，继续展示原书例句、用法和相关词。
- 真题区展示正文检出次数、结构提示、对应年份的完整原句和逐句中文翻译。

## 本地运行

```bash
npm install
npm run extract:vocab -- /path/to/考研大纲词汇乱序版.pdf
npm run dev
```

## 验证

```bash
npm test
npm run build
```

## 发布

推送到 `main` 后，GitHub Actions 会运行测试、构建 `dist/`，并发布到 GitHub Pages。仓库公开可访问，但不会内置原 PDF，也不接入分析服务。
