# 考研单词

个人使用的离线背词 PWA。每天最多 15 组、每组 20 词；只有明确标为熟词的词退出学习池，其余词在整轮结束后继续学习。

线上版本：https://zwh0527-creater.github.io/kaoyan-vocab/

词库来自 `考研大纲词汇乱序版.pdf`，提取后共 5493 条。两个 `coordinate` 条目含义不同，按原 PDF 顺序保留；另从考研词汇书中本地筛选出 1760 条常见搭配，原 PDF 不会打包进 App。学习进度只保存在当前设备，可在设置页导出和导入 JSON 备份。

## 学习规则

- 每次只显示当前 20 词小组，中文释义默认隐藏。
- 未标熟词不会第二天立刻重复；当前整轮完成后，它们才进入下一轮。
- 熟词进入熟词本。只有逐词点击“重新学习”，对应单词才回到下一轮队列。
- 详解只提供基础释义和经过筛选的考研常见搭配；没有可靠搭配时保持空缺。

## 本地运行

```bash
npm install
npm run extract:vocab -- /path/to/考研大纲词汇乱序版.pdf
npm run dev
```

## 验证

```bash
npm test
npm run build
```

## 发布

推送到 `main` 后，GitHub Actions 会运行测试、构建 `dist/`，并发布到 GitHub Pages。仓库公开可访问，但不会内置原 PDF，也不接入分析服务。
