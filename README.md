# 考研单词

个人使用的离线背词 PWA。每天中午 12 点刷新，最多 15 组、每组 20 词；只有明确标为熟词的词退出学习池，其余词在整轮结束后继续学习。

支持中文反查和英文查词，并显示熟词状态。词条始终先展示考研大纲原释义，红宝书释义作为有页码的补充；英语一真题记录来自本地 2010—2025 真题合集，提供完整原句、中文译文和用法结构。与原句、真实年份和本地答案资料逐题核对一致的内容标为“官方译文”；AI 对照英文逐句校订的内容标为“校订译文”。固定搭配、例句及相关词来自红宝书本地 OCR 提取，并区分“原书未设词组栏”和“OCR 未形成可靠条目”。

线上版本：https://zwh0527-creater.github.io/kaoyan-vocab/

词库来自 `考研大纲词汇乱序版.pdf`，提取后共 5493 条。两个 `coordinate` 条目含义不同，按原 PDF 顺序保留；原 PDF 不会打包进 App。学习进度只保存在当前设备，可在设置页导出和导入 JSON 备份。

## 学习规则

- 每次只显示当前 20 词小组，中文释义默认隐藏。
- 未标熟词不会第二天立刻重复；当前整轮完成后，它们才进入下一轮。
- 熟词进入熟词本。只有逐词点击“重新学习”，对应单词才回到下一轮队列。
- 详解优先提供可核对的红宝书固定搭配；没有单列搭配时，继续展示原书例句、用法和相关词。
- 真题区展示已收录语境数量、结构提示、经来源核查的年份、合集 PDF 页码、原句和中文译文。语境数量不是历年出现频次。

## 本地运行

```bash
npm install
npm run extract:vocab -- /path/to/考研大纲词汇乱序版.pdf
npm run dev
```

## 真题译文校订

`scripts/data/exam-translation-overrides.json` 按完整英文原句保存校订和原因；标为“校订译文”，不会冒充官方答案。新增校订后运行 `npm run clean:translations`，会同步翻译缓存、所有词条引用和详情指纹，不改词义与学习数据；开发或构建时会重新生成详情分块。Node 与 Python 数据生成器读取同一份校订表，避免重新生成时退回旧机器译文。仅已验证的官方译文保留答案题号。

`scripts/data/exam-context-review.json` 保存每条原始句子的保留或排除决定、原 PDF 页码和年份，以及必要的 OCR 修正。排除项包括混入的答题指令、残缺题干和参考范文。两套数据生成器共用这份记录；已审条目不会再次由错误年份匹配到另一年的答案。PDF 页码指本地合集的文件页序，不是卷面印刷页码。审校由 AI 完成，不声称人工逐句验证。

```bash
node scripts/audit-exam-translations.mjs --check
node scripts/audit-exam-translations.mjs --output /tmp/exam-translation-review.json
```

审查队列按原句去重，保留年份、词条和短语定位。优先级 0 是未审原句重新进入数据、已排除项重现、来源漂移、缺失译文或残留题号等数据错误；1 是疑似漏译、译文未结束或 OCR 问题；2 是其余机器译文；3 是未触发规则的非机器译文。字数比和标点仅用于排序，需要逐句核对，不能据此批量认定译文正确或错误。`--check` 只在出现优先级 0 时失败。

本轮逐句审查原始 1,658 条：保留 1,545 条，排除 113 条；修改 1,463 条译文、281 条英文识别文本和 747 条年份。保留内容中 12 条逐题核实为官方译文，其余标为 AI 校订译文。

审查覆盖数、译文修改数和排除数记录在来源审查表的 `coverage` 中；回归检查要求原始 1,658 条逐一有处理记录，并验证界面使用的数据与记录一致。字数比等启发式检查不等于语义审查，也不应成为跳过逐句检查的依据。
